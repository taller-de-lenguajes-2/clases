Composición y agregación

Cómo se asocian las clases para construir una aplicación

Construyendo un sistema

Una aplicación orientada a objetos está constituida por múltiples clases que interactúan entre sí por medio de mensajes, cada una con una responsabilidad y una tarea particular.

  • Cada clase es una abstracción con una responsabilidad clara
  • Las clases colaboran enviándose mensajes (llamando métodos)
  • Todas juntas proveen el comportamiento esperado de la aplicación
A la estructura, funcionamiento e interacción entre las partes del software la llamamos arquitectura — como los planos de un edificio.

¿Cómo podemos vincular clases?

Una asociación es un tipo de relación donde una clase contiene a otra: una clase es miembro de otra clase.

  • Tipos de asociación: composición y agregación
  • Se implementa declarando un miembro cuyo tipo es otra clase
public class Posicion
{
    public int X { get; set; }
    public int Y { get; set; }
}

public class Rectangulo
{
    // Rectangulo contiene una Posicion
    public Posicion MiPosicion { get; set; }
}

Composición — “es parte de”

  • Es la relación más fuerte entre clases
  • El objeto contenido no puede existir independientemente del que lo contiene
  • El tiempo de vida del miembro está condicionado por el del contenedor
El Salón es parte de un Colegio: si el colegio deja de existir, sus salones también.
public class Colegio
{
    // los salones viven dentro del colegio
    private List<Salon> aulas = new();
}

Agregación — “tiene un”

  • Relación más débil que la composición
  • El objeto contenido puede existir con independencia del que lo contiene
El Curso tiene Estudiantes: si el curso se cierra, los estudiantes siguen existiendo.
public class Curso
{
    // el estudiante existe fuera del curso
    public Estudiante Alumno { get; set; }
}

Ejemplo: Vehículo

public class Motor
{
    public Motor() { … }
}

public class Rueda
{
    public Rueda() { … }
}
public class Vehiculo
{
    public Motor MotorDeVehiculo { get; set; }
    public List<Rueda> Ruedas { get; set; }

    public void Acelerar() { … }
    public void Frenar() { … }
}
  • El Motor forma parte de un Vehículo → composición
  • El Vehículo tiene una o varias Ruedas → agregación
