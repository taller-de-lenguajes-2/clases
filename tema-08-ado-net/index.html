¿Qué es ADO.NET?

El conjunto de clases de .NET para acceder a datos. Cada motor trae su proveedor; las ideas son las mismas.

Agregar el proveedor de SQLite

dotnet add package Microsoft.Data.Sqlite
using Microsoft.Data.Sqlite;
En internet van a encontrar nombres parecidos, de otras librerías: SqliteConnection (la nuestra) · SQLiteConnection (System.Data.SQLite) · SqlConnection (SQL Server). Mismas ideas, no se mezclan.

Los tres objetos que usamos

SqliteConnection

Abre y cierra la conexión con la base.

SqliteCommand

Lleva una orden SQL y la ejecuta.

SqliteDataReader

Recorre el resultado de un SELECT, fila por fila.

ADO.NET tiene más (DataSet, DataAdapter…), pero en la materia alcanza con estos tres.

Cadena de conexión

Un texto con pares clave=valor, separados por ;, que dice dónde está la base y cómo entrar.

SQLite

"Data Source=clinica.db"

El archivo. Si no existe, lo crea.

SQL Server

"Server=localhost;Database=Clinica;
 Trusted_Connection=True"

Servidor, base y usuario.

Las claves las define cada proveedor: no son iguales entre motores. Version=3 es de System.Data.SQLite: en Microsoft.Data.Sqlite tira ArgumentException. La ruta clinica.db es relativa a la carpeta desde donde corre el programa.

Abrir la conexión

var cadenaConexion = "Data Source=clinica.db";

using var conexion = new SqliteConnection(cadenaConexion);
conexion.Open();

// … comandos …

// al terminar el método (el bloque donde se declaró), using llama a Dispose() y la conexión se cierra

Con using

Se cierra siempre, aunque salte una excepción (tema 16). No hace falta Close().

Abrir tarde, cerrar temprano

Una conexión por operación: se abre, se usa y se suelta.

Forma equivalente, con llaves: using (var conexion = new SqliteConnection(cadena)) { … }. En código asíncrono: await using y OpenAsync().

Todo junto: listar pacientes

public List<Paciente> ListarPacientes()
{
    var pacientes = new List<Paciente>();

    using var conexion = new SqliteConnection(cadenaConexion);  // 1
    conexion.Open();

    var sql = "SELECT Id, Nombre, DNI, Telefono FROM Paciente ORDER BY Nombre";
    using var comando = new SqliteCommand(sql, conexion);       // 2
    using var lector = comando.ExecuteReader();

    while (lector.Read())                                         // 3
    {
        pacientes.Add(new Paciente
        {
            Id       = lector.GetInt32(0),
            Nombre   = lector.GetString(1),
            DNI      = lector.IsDBNull(2) ? null : lector.GetString(2),
            Telefono = lector.IsDBNull(3) ? null : lector.GetString(3)
        });
    }
    return pacientes;
}

Insertar y obtener el Id

public int InsertarPaciente(Paciente paciente)
{
    using var conexion = new SqliteConnection(cadenaConexion);
    conexion.Open();

    var sql = """
        INSERT INTO Paciente (Nombre, DNI, Telefono)
        VALUES (@nombre, @dni, @telefono)
        RETURNING Id
        """;
    using var comando = new SqliteCommand(sql, conexion);
    comando.Parameters.AddWithValue("@nombre", paciente.Nombre);
    comando.Parameters.AddWithValue("@dni", (object?)paciente.DNI ?? DBNull.Value);
    comando.Parameters.AddWithValue("@telefono", (object?)paciente.Telefono ?? DBNull.Value);

    return Convert.ToInt32(comando.ExecuteScalar());
}
  • RETURNING Id devuelve el Id que generó la base (otra forma: SELECT last_insert_rowid() después del INSERT)
  • Por eso, ExecuteScalar()
  • Un null de C# se manda como DBNull.Value

Cuando la base dice que no

try
{
    datos.EliminarPaciente(1);   // Ana tiene turnos
}
catch (SqliteException ex)
{
    Console.WriteLine(ex.Message);
}
SQLite Error 19: 'FOREIGN KEY constraint failed'.
  • La integridad referencial del tema 07, ahora como excepción
  • También: base inexistente, SQL mal escrito, UNIQUE repetido…
  • Se manejan como en el tema 16
  • SQLite controla las FK por conexión (PRAGMA foreign_keys = ON). Microsoft.Data.Sqlite ya las activa; para no depender de eso: "Data Source=clinica.db;Foreign Keys=True"

La receta

  1. using var conexion = new SqliteConnection(cadena); y Open()
  2. Escribir el SQL, con @parámetros para todo lo que venga de afuera
  3. using var comando = new SqliteCommand(sql, conexion); + Parameters
  4. Ejecutar: ExecuteReader · ExecuteNonQuery · ExecuteScalar
  5. Si hay filas: while (lector.Read()) → objetos

Al terminar el método, los using cierran todo.
