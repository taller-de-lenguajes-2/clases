Objetivos de la materia

  • Conocer un lenguaje orientado a objetos en el entorno de desarrollo .NET
  • Desarrollar aplicaciones orientadas a objetos trabajando sobre una base de datos
  • Comprender los conceptos de arquitectura de una aplicación y cómo aplicarlos
  • Construir y consumir servicios web (API REST) sobre HTTP
  • Adquirir nuevas competencias en la elaboración de aplicaciones (sesiones, excepciones, logs)

La materia — los contenidos

POO en C#

ASP.NET Core

  • API REST · HTTP
